# Channels and settings

## Choose channels

Open **SpikerBox → Channels**. The list reflects the channels available from the connected device or opened recording. Turn on the channels you want to work with.

For a new recording, make this choice **before Record**: only the channels enabled at the start are included. Channels cannot be reconfigured while recording.

For an existing recording, hiding a channel changes what you see; it does not erase that channel's recorded signal.

## Configure the signal

Use **Configure channels** inside the Channels panel to reach the channel configuration card. Choose the relevant channel and preparation, and review the available filter and notch settings. Confirm the configuration when finished.

A preparation supplies settings appropriate to that type of signal. Filters change which frequencies are emphasized or reduced. A notch filter targets a narrow frequency such as mains interference. Start with the setup described in your [device's guide](/#choose-your-device), and record any filter choices that matter to your experiment.

Adjust the displayed amplitude and time scales to inspect the trace. Display magnification alone does not increase the biological signal or fix a noisy electrode contact.

## Select a channel for analysis

Detect uses the selected channel's threshold. Select the intended channel before moving that threshold. Spectrum also uses a selected channel; use its channel control when more than one channel is available.

## App settings

Open **SpikerBox → Settings** for display preferences and the app's version information. This is also where you can check the installed version when reporting a problem.

Use **SpikerBox → Events** for event labels. That menu is separate from the Events analysis tab at the bottom.
